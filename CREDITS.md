# Credits and third-party boundaries

TPFC Quiet is a new native C++17 interface and service/control implementation developed with Codex for one owner's ThinkPad.

Its EC register conventions and compatibility investigation build on [Shuzhengz/TPFanCtrl2](https://github.com/Shuzhengz/TPFanCtrl2), particularly version 2.3.3. That project's history credits [ThinkPad-Forum/TPFanControl](https://github.com/ThinkPad-Forum/TPFanControl) and [byrnes' dual-fan modification](https://github.com/byrnes/TPFanControl). The existing source tree's Unlicense is retained.

- TVicPort is a separately installed EnTech component. No TVicPort driver or DLL is distributed here.
- Lenovo Vantage components provide the named temperature data on the tested machine. No Lenovo DLL, service binary, or documentation dump is distributed here.
- Microsoft compiler and Windows SDK files are build prerequisites and are excluded.
- The fan mark included in `quiet/assets` is generated by `tools/make_icon.py`.
- Publication diagrams are original explanatory graphics. The application image is an unretouched window capture. These are not measurements of noise reduction.

Protocol background: [ACPI 6.6 embedded-controller interface](https://uefi.org/specs/ACPI/6.6/12_Embedded_Controller_Interface_Specification.html).
